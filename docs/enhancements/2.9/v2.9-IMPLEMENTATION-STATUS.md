**Notes:**
- Readiness cache TTL (default 2s) is a pragmatic balance: long enough to keep preflight overhead near zero on rapid back-to-back execs, short enough that a recently stopped container surfaces as `not_running` within the next request cycle.

- MCP probe writes are best-effort (caught + logged) so a transient DB failure never masks the actual probe result.
