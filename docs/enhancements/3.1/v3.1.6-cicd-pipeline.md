## Implementation Notes

### Codecov Update (Item 1)

Change `codecov/codecov-action@v3` to `codecov/codecov-action@v4`. V4 requires an explicit `token` parameter (v3 allowed unauthenticated uploads for public repos).

### E2E Job (Item 2)

Add a new job after `build` that:
1. Starts PostgreSQL + Redis services (same as test job)
2. Installs Playwright browsers (`npx playwright install --with-deps chromium`)
3. Starts the dev server in background
4. Runs `npm run test:e2e`
5. Uploads trace artifacts on failure

### Staging Deploy (Item 3)

Add a workflow triggered on push to `main` that:
1. Builds the production Docker image
2. Pushes to container registry (GitHub Container Registry or Cloudflare R2)
3. Optionally triggers a staging environment deploy
