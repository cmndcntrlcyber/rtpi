## Purpose

This document is the Phase 1 deliverable of v3.3. It contains the exhaustive tool manifest extracted from every RTPI container Dockerfile, cross-referenced against nexus-harness `skills/offense/` coverage, with each tool classified as **COVERED**, **PARTIAL**, or **GAP**.

Tools marked GAP require new nexus-harness skills, MCP configurations, or templates — each planned under `v3.4.<N>-<tool-name>/` subdirectories.

System packages (curl, wget, git, build-essential, etc.) shared by the `offsec-base` image are excluded from the gap analysis — they are standard utilities available in nexus-kali by default.
